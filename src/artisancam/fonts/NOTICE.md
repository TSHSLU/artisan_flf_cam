# Bundled font

`ISO3098-Regular.svg` is a single-line (stroke) SVG font in the style of ISO 3098
engineering lettering. It was copied unmodified from the `ivacam` project
(`crates/ivac-core/assets/fonts/`).

**Provenance and licence are NOT verified.** Fine for private use of this prototype;
check the licence before sharing or distributing this repository. Swapping the font
only touches `font.py` and `config.toml` (`char_advance`).
